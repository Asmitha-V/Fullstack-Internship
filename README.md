## 🚀 How to Run the Project

### Task 1: Weather API Integration
1. Open `index.html` in a web browser
2. Click **Get Weather** to view live temperature data

### Task 2: Real-Time Chat Application
1. Install Node.js
2. Run `npm install`
3. Start server using `node server.js`
4. Open `http://localhost:4000` in the browser
5. Open the page in multiple tabs to test chat

### Task 3: Collaborative Document Editor
1. Install Node.js
2. Run `npm install`
3. Start server using `node server.js`
4. Open `http://localhost:4000` in multiple browsers
5. Start typing to see real-time collaboration

### Task 4: Chrome Extension – Time Tracker
1. Open Chrome → `chrome://extensions`
2. Enable **Developer Mode**
3. Click **Load unpacked**
4. Select the extension folder
5. Start the backend server using `node server.js`
6. Browse websites and open the extension popup
